For loop तेव्हा वापरतो जेव्हा किती वेळा loop चालणार आहे ते आधीच माहित असते.



initialization → सुरुवातीला एकदाच चालते



condition → true असेल तर loop चालतो



code execute



increment/decrement → value बदलते



पुन्हा condition check होते



for(initialization; condition; increment/decrement)

{

&nbsp;   // code

}



While loop तेव्हा वापरतो जेव्हा किती वेळा loop चालेल ते माहित नसते.

while(condition)

{

&nbsp;   // code

}



condition check



true असेल तर code run



value change



पुन्हा condition check



Do-while loop मध्ये code किमान एकदा तरी run होतो.

do

{

&nbsp;   // code

}

while(condition);

code run



condition check



true असेल तर पुन्हा run





| Loop     | Condition Check| Minimum Run|

| -------- | ----------| ----------- |

| for      | सुरुवातीला      |     0        |

| while    | सुरुवातीला      |     0        |

| do-while | शेवटी           |      1        |
